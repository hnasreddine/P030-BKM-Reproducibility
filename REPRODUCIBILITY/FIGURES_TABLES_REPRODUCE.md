# P030 — Reproducing the numerical tables and figures

This page concerns the **four nonduplicated main-text table datasets**, **twelve supplementary table datasets**, and **two figures** of the
JMP manuscript. The exact-moment single-point continuum certificate uses the
separate `exact_m2_certificate/` programs; it has different assumptions from
older rounded-SVD numerical experiments.

## From a clean Linux checkout

Use Python 3.13. Install the figure dependencies in addition to the existing
scientific requirements:

```bash
python -m pip install -r requirements-figures.txt
python tools/verify_release.py
python tools/verify_paper_reproduction.py
```

The second test reconstructs manuscript tables from recorded simulation outputs, checks
recorded bath-grid convergence and unresolved-point handling, generates four main-text and twelve supplementary LaTeX table-row fragments,
generates both PDF figures, and deliberately corrupts
a source dataset to ensure that **a mismatched result is rejected**.

Manual regeneration, from any current working directory:

```bash
python REPRODUCIBILITY/code/make_tables.py --check
python REPRODUCIBILITY/code/make_supplementary_tables.py --check
python REPRODUCIBILITY/code/make_figures.py
python REPRODUCIBILITY/code/make_figure_nonnormal.py
```

Outputs are written into `REPRODUCIBILITY/generated/tables/` and
`REPRODUCIBILITY/generated/figures/`; these build artifacts are untracked.
All generated table values are calculated from recorded data, then compared
cell-for-cell with `reference/published_table_rows.json` (four main-text tables)
and `reference/published_supplement_table_rows.json` (twelve supplementary tables).
For the two latest supplementary order-two tables, the generator uses
`order2_high_precision/direct_m2_results.json` and the numerical constants
contained in `exact_m2_certificate/final_error_budget.py`.

If the author-supplied LaTeX `numerics_section.tex` is available, reproduce its
**scientific numerical entries from recorded outputs exactly**, without replacing any prose, captions,
or authorship/policy disclosure:

```bash
python REPRODUCIBILITY/code/make_tables.py --check \
  --manuscript-section /path/to/paper/numerics_section.tex \
  --rebuild-section /tmp/numerics_section_rebuilt.tex
sha256sum /path/to/paper/numerics_section.tex /tmp/numerics_section_rebuilt.tex
python REPRODUCIBILITY/code/make_supplementary_tables.py --check \
  --supplement-section /path/to/supplement/P030_Supplementary_Numerics_v0.9.tex
```

The paper's editorial text is not synthesized from numerical data; the script
changes **only** numeric rows inside the four recognized table labels.
When the manuscript LaTeX is supplied separately, the source-section and rebuilt-section
SHA-256 digests should match. This archive does not require or include the manuscript source.


**Dataset lineage:** Main Table V (fixed versus shrinking contours) presents the same underlying rows as supplementary Table IV (`tab:fixedcontour`). In the associated manuscript the fixed-contour table is kept only in the supplement; the manuscript text references that table. Four independent main-table datasets and twelve supplementary datasets are checked, and the fixed-contour rows are therefore checked once in the supplement, not counted as a separate fifth dataset. Numeric table generation here does not rerun the original high-cost reservoir propagation. The exact single-point bath replay is separately available through `RUN_EXACT.sh`.

The twelve supplementary tables (`tab:recon`, `tab:ep`, `tab:clusters`,
`tab:fixedcontour`, `tab:m1`, `tab:v03`, `tab:m2`, `tab:m2directhp`,
`tab:m2certbudget`, `tab:H`, `tab:nonnormal`, `tab:generic`) are generated by
`code/make_supplementary_tables.py` from the archived data and validated budget.
Ten source tables are reconstructed by the recorded data-generation formulas;
the two later order-two tables use their separate high-precision and certified
error-budget sources. The script writes **table rows only**; it does not generate narrative text.

The plots are regenerated from recorded numerical outputs and reproduce the **same underlying curves, markers, threshold positions
and unresolved-point filtering**. Embedded PDF font metrics and vector paths
can differ across Matplotlib versions. No byte-identical PDF claim is made.

## Boundaries

1. The generated numerical-table rows are checked against an independently
   captured source reference; generating identical rows merely by copying a
   manuscript file is prohibited by the regression test.
2. The reference scientific tables do not infer a continuum bound from
   recorded bath-grid agreement. Only the *separate* exactly orthogonal
   parameter point has the conditional certified continuum enclosure.
3. This workflow generates the numerical scientific content, not an entire
   LaTeX article or supplementary manuscript; human-authored exposition and
   cross-references are preserved when rebuilding the author's section.
