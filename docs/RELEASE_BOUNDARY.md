# Public/private boundary (v1.0.0)

## Public repository — software, data and proofs only
This archive contains the author-owned source code, microscopic input tokens,
computed outputs, numerical tables, the mathematical certificates, and
source-level verification programs strictly necessary to reproduce the results
in the article and its supplement. All data files are small enough for Git.
The scope of the exact-m2 BKM certificate is the single specified parameter
point, not all historical tables.

## Private scholarly workspace — not part of this public archive
Manuscript and supplement TeX/PDF, private ARI research records, internal AI
or human referee reports, internal feedback, unpublished correspondence,
prompts and conversations, credentials and service tokens remain private.
This archive does not expose `ari_manuscripts` or any corporate/security code.

## Publication boundary
The public repository proposed name is
`hnasreddine/P030-BKM-Reproducibility`, a separate sibling of P014, never a
folder in P014. The immutable release will be tied to the exact git commit and
a passing GitHub Actions run. Zenodo version DOI is referenced only after it
exists. The manuscript's Data Availability text must be updated with that DOI
before final journal submission. The author reviews all licenses, rights,
scientific claims and submitted material.
