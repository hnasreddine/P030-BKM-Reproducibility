# Relation to existing P014 public certificate

P014 `P014-Tetrahedral-Quantum-Certificate` is a separate exact algebraic SOS
certificate, with two verification routes, GitHub CI, release tags and a Zenodo
version DOI. P030 uses the same **release-engineering standards**: isolated
public repository, SHA256 integrity, executable quick/full checks, proof map,
scoped licensing, GitHub Actions and version DOI upon archival publication.

Their mathematical scopes are not equivalent. P014 targets an algebraically
exact global certificate; P030's computer-assisted BKM enclosure is limited to
one explicitly specified physical model/parameter point and requires a
floating-point/interval-library trusted base. Neither subsumes the other.
